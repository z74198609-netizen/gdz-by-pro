# GDZ BY PRO

Мобильный учебный помощник: выбор класса и предмета, ввод задания и получение пошагового решения через серверный API.

## Запуск
- Build: `npm install`
- Start: `npm start`
- Environment: `OPENAI_API_KEY` (хранить только в настройках хостинга, не в HTML).

Подробности — в `README_RU.txt`.
